# Release notes

## v1.0.0 — Initial public release

- Publish RSVP Reader firmware v13 for Arduino-Pico / RP2040.
- Include STL meshes for the three-part handheld enclosure.
- Add project photos, component inventory, provisional wiring notes, assembly guide, and firmware/book installation guide.
- Firmware features RSVP playback, 140–200 WPM speed selection, LittleFS `.txt` book storage, saved progress/configuration, rewind, restart, and sleep.

### Known documentation gaps

- Editable CAD source and slicer profile are not available.
- OLED I²C pin mapping, OLED module voltage, exact charger protection variant, battery power path, fasteners, and wire lengths should be confirmed against the physical build before others reproduce it.
